## Descripción
Aplicación en C para gestionar un único producto: registro (ID, nombre, stock, precio), ventas con validación de stock y **descuento**, **reabastecimiento**, **consulta** del estado y **ganancias acumuladas**.

## Compilación y ejecución
```bash
gcc -Wall -Wextra -O2 -o tienda tienda.c
./tienda   # En Windows: tienda.exe
